## Context: what we have already built

A self-hosted, CryptoPanic-style **real-time crypto news terminal**. It runs locally on a Windows 11 PC. It works end to end, but the news it shows is fake (generated by a mock script).

**Stack**
- Frontend: Next.js 15 (App Router), React 19, TypeScript, Tailwind, Zustand. A dark, dense, terminal-style UI with three columns.
- Backend: Next.js API routes, PostgreSQL 18 via Prisma, Redis 8 (hot list + pub/sub), and a separate Node WebSocket server (`ws`).
- Ingestion: `ingest.js` currently inserts a FAKE article every 5 seconds. **This is the part to replace.**

**Data model:** Post(id, title, url unique, sourceDomain, publishedAt, kind news/media/blog, sentiment bullish/bearish/neutral) is linked many-to-many to Instrument(ticker, name) and one-to-one to VoteData(bullish, bearish, important, toxic).

**Pipeline today**
1. The ingest worker creates a post and inserts it into Postgres.
2. It LPUSHes the post to Redis `news:hot` (capped at 1,000) and PUBLISHes it on `news:new`.
3. The WebSocket server broadcasts it to the browser in under a second.
4. Votes update Postgres and the Redis hot list, then broadcast `news:update`.

**Features working and tested**
- Live feed with a "N new posts" bar, so rows don't jump while reading.
- Filters: All / Hot / Rising / Bullish / Bearish.
- Portfolio ticker filter.
- Trending coins.
- CoinGecko price widget.
- In-app article pages.
- One vote per type per post.
- Cursor pagination ("Load older").
- Automatic reconnect with REST re-sync.
- Protection against votes being sent from other websites (CSRF).
- Services bound to localhost only.

**Ticker tagging today:** whole-word regex matching against a dictionary of 30 coins (name, ticker, aliases such as "vitalik" → ETH). **Sentiment today:** random, because the news is fake.
